# Nuvia · Dashboard inmobiliario (prototipo visual)

- `index.html`: versión completa, se abre con doble clic en el navegador (Chrome o Edge). Carga las fuentes desde Google Fonts.
- `src/`: el mismo código dividido por partes, en el orden en que se unen (estilos, estructura, datos, núcleo y gráficos, vistas, paneles y eventos).

Todos los datos son ficticios (generados en `src/3-datos.js`). Cuando exista el back, reemplazar ese archivo por llamadas a la API.

Plan de producto, marca, historias de usuario y prompts de Claude Design: documento "Nuvia · Plan de producto, marca y vista 3D" en Claude.
